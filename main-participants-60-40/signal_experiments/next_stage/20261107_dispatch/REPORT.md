## The forecasting problem

For each simulated slot machine, predict the probability of each possible **next-spin payout: 0×, 1×, 2×, 5×, or 20×**. Each episode groups eight machines at a common prediction tick. The inputs are machine type, the signal recorded at that tick, and the observed payout history strictly before it. Some histories contain only 40 recent consecutive spins plus 24 older observations. A gap means the outcome is unknown. [Data dictionary](../../../DATA.md)

The main challenge is to infer each machine's win rule from past outcomes. Earlier spins can interact at lags up to eight ticks, and the direction of that relationship can change. Some changes happen at nearly the same time across the eight machines. A separate part of the forecast estimates the payout size conditional on a win. The branch baselines and our follow-up experiments test which parts of that structure help on stable, short-history, drift, and shared-change episodes. [Model and evidence handoff](../../../HOUSE_EDGE_AI_HANDOFF.md)

**Scoring.** Compare all five forecast probabilities with the simulator's true probabilities by squared error. Average within episodes and then within each condition. Divide each condition's error by its frozen reference error and average those four ratios to get `R`. Lower `R` is better. The main score is `60 / (1 + R)`. Adaptation uses a new kit with changed temporal patterns, its own frozen reference, and `40 / (1 + R)`. This report's contest scores use 96 released **main** validation episodes and 768 queries. The organizer holds the test answers. [Rules](../../../RULES.md) · [Main data metadata](../../../public/metadata.json)

## Main candidate

**Advance W1a + P0.** The pooled ordered-cell win head and hard type-tail projection scored **56.425331 / 60**, versus 56.341022 for the frozen hybrid and 55.268370 for frozen M3. The paired change versus the hybrid was **ΔR −0.001591 [−0.002449, −0.000821]**. All four condition ratios improved, as did (4,7) p0 MSE and overall tail SSE. Removing either component reduced the score with a paired interval below zero for the assembled candidate relative to the ablation. W2 + P0 scored 56.426385. Its gain versus W1a + P0 had a paired interval crossing zero, so the simpler candidate advanced. [Selection and component checks](coordinator/MAIN_CANDIDATE.md)

**How it works.** M3 infers which two lagged spins drive the machine's win odds and whether that rule reversed. W1a keeps those beliefs and distinguishes ordered win/loss pairs such as `01` and `10` when forecasting the next win. The lag-pair LightGBM and three factored GRUs supply the conditional payout mix. P0 keeps the resulting 0× and 1× probabilities and splits the remaining mass among 2×, 5×, and 20× in fixed ratios learned from training histories by machine type. **Evaluation caveats.** The new historical evaluation tools score sampled spins. They inherit the actual-cutoff signal at earlier pseudo-cutoffs, which can affect signal-aware arms such as M3. The short-history backtest also uses the first hidden spin as the new training label on train short episodes and pools those episodes into its scored set. That first scored tick overlaps training supervision for models that use those labels. A held-episode comparison should exclude that overlap and use neutral historical signal. [Tail evaluation](https://github.com/Amir-Suh/TAMU-Datathon-2027/blob/562f826bdcb6505fbe7428381a4dca20b7b4e5be/src/tdx/tools/tail_eval.py) · [Short-history backtest](https://github.com/Amir-Suh/TAMU-Datathon-2027/blob/562f826bdcb6505fbe7428381a4dca20b7b4e5be/src/tdx/tools/short_backtest.py)
