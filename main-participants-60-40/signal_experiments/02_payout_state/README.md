# Conditional payout state

The public validation probability vectors have two values of P(1× | win) per machine type, with a fixed ratio for the other three positive payouts. The estimated low and high levels are 0.455 and 0.754 for steady, 0.214 and 0.500 for balanced, and 0.121 and 0.335 for jackpot.

The primary model estimates the high state's probability from the machine type and observed own-machine history. Each 16-, 40-, 96-tick and all-history window contributes a shrunken 1× share among wins, a win count and a shrunken win rate. Missing ticks contribute no observations. The model standardizes these features and fits ridge logistic regression with `C=0.1`. The query's signal and condition are excluded from the features.

Each of the four folds holds out 24 complete episodes. Each fold estimates the two levels, tail ratios, scaler and classifier on its other 72 episodes. At prediction time the estimated state probability mixes the two 1× levels. The fold-trained tail ratios divide the remaining conditional mass. A constant mixture instead uses each type's empirical high-state rate from the same fold training set. The weighted secondary model weights each training row by frozen M3 P(win)², mean-normalized within its fold.

Each forecast copies the frozen M3 `p_0` field verbatim and preserves bitwise equality after the official checker's floating-point normalization. Only the conditional distribution of positive payouts changes. Held-out probability vectors supply official losses and diagnostic state labels after inference.

The history model achieved state AUC 0.731 and state Brier loss 0.2085 versus 0.2501 for the constant mixture. Its unweighted conditional payout SSE fell from M3's 0.02553 to 0.02361, while the win-mass-weighted conditional payout SSE rose from 0.01020 to 0.01026. The official point gain was 0.0097 with mixed condition results. These results support retaining frozen M3 as the default. Public validation informed the two-state hypothesis and has been reused for development. The paired bootstrap resamples held-out episodes with fixed forecasts, so it describes variation across these episodes conditional on the fits.

`validation_predictions.csv` is the primary out-of-fold forecast. `test_predictions.csv` is a separate candidate generated by fitting on all public validation episodes and replacing the frozen M3 main test head. The official checker accepted both files. Hidden main test and adaptation scores are unavailable.

Run from the participant-kit root using NumPy 1.26.4 and scikit-learn 1.6.1.

```sh
d=signal_experiments/02_payout_state
python3 -B "$d/run.py" --m3-test m5_m6_repair/results/repaired-m5-m6/m3/submission.csv
python3 -B signal_experiments/score.py --out "$d/paired_scores.json" \
  "payout_state=$d/validation_predictions.csv" \
  "constant_mixture=$d/constant_mixture.csv" \
  "weighted_secondary=$d/weighted_secondary.csv"
python3 -B check_submission.py "$d/validation_predictions.csv" --split validation
python3 -B check_submission.py "$d/test_predictions.csv"
```
