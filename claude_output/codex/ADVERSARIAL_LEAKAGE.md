## The task being scored
Each query is one slot machine at its `cutoff` tick (8 machines per episode, one cutoff per episode). We predict `[p_0, p_1, p_2, p_5, p_20]` for the NEXT tick. Score = squared error against the simulator's TRUE probabilities. Data splits: train (labels = realized outcome at the cutoff, condition labels), validation (true probabilities + condition + reference), test (no answers). History files contain only ticks `< cutoff`. `signal` (-1/0/1) exists ONLY in `queries.csv`, once per machine, at the cutoff. `n_obs == 64` marks short_history episodes. Rules: test answers and private files are off limits; observations must be strictly before the prediction tick, "including when making training examples from earlier history"; self-supervised use of validation and test HISTORIES (ticks < cutoff) is allowed; the organizers rerun our code offline (Python 3.13, 2 cores, 16 GiB) and compare to the uploaded CSV within 1e-8.
