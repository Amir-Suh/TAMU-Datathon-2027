## What to build
Background: a `short_history` machine shows exactly 64 observed ticks before the cutoff: the last 40 consecutive ticks plus 24 older ticks sampled at random (everything else missing). Our GRU/transformer arms are trained mostly on full histories, so they see this layout only in 24-48 episodes.
1. `sampler.py`: `sample_layout(y_row, cutoff_prime, rng)` -> (tokens[64] int8 in {0..4}, offsets[64] int16 = cutoff_prime - tick) where the 40 most recent observed ticks are cutoff_prime-40..cutoff_prime-1 (all must be observed) and the 24 older ticks are drawn without replacement from observed ticks < cutoff_prime-40; deterministic given `rng`; return None when the machine does not have 64 observed ticks before cutoff_prime. A vectorised batch version must produce training batches of (tokens, offsets, mtype, target) where target = the REALIZED outcome class at tick cutoff_prime (must be observed; cutoff_prime ranges from tick 80 up to the machine's real cutoff - 1 for all machines of train, validation, test; the real cutoff tick itself is never a target).
2. `arm.py` (`ShortCtxArm`): input = the 64 items (class embedding + learned embedding of offset bucket [0..39 individually, then log-spaced buckets up to 255] + machine-type embedding). Encoder: a causal-order GRU over the 40 consecutive ticks (oldest to newest) concatenated with a mean-pooled embedding of the 24 older items (permutation invariant), fed to an MLP head producing 5 logits with the factored win/size head used in `seq` (win logit + 4 size logits -> log-probs). Train with cross-entropy on the realized next outcome. Mixed training: 50% exact-layout samples and 50% full-history samples built as the last 64 observed ticks (so the same weights serve long histories; the flag embedding = observed count == 64 of the row actually given). Epochs/batch: choose so one training takes <= 15 minutes on the shared GPU.
3. Inference: pure numpy float64 (`forward_np`), torch imported only inside `fit`; `predict(split)` builds the layout from `split.y` and `split.cutoff` for every machine: if the machine has exactly 64 observed ticks use them as given; otherwise take the last 40 consecutive + 24 random older observed ticks (seed fixed) — document this. `save`/`load` exact round trip (model.npz + meta.json). torch-vs-numpy parity < 1e-6 checked after every fit.
4. `__init__.py`: `VARIANTS = {'pilot': {...}}` (all hyper-parameters, `transductive=True`) and `build(**params)`.
