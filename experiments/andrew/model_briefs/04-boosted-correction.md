# Assignment 04 · Boosted correction of adaptive win odds

## Goal

Train a small model that adjusts the current adaptive win probability when the historical evidence suggests that its forecast is too close to 0.5, biased, or unstable. The existing global two-stage model reached 31.444 with self history alone. The adaptive model reached **33.224516/60**. Its 10th and 90th percentiles for `p_0` were 35.1% and 90.8%, versus 3.9% and 98.9% for the true tuning probabilities. Test whether an offset learner can correct errors while retaining the useful local forecast. [Adaptive model](../slot_forecasting/adaptive.py), [existing features](../slot_forecasting/causal.py), [comparison](../runs/model-comparison/comparison.json).

Gradient boosting fits additive corrections to a prediction function under a chosen loss. Stacking trains on predictions made for examples held out from the first-stage model. Together these ideas motivate fitting a regularized correction to a causal, out-of-episode adaptive logit. [Friedman, Gradient Boosting Machine](https://doi.org/10.1214/aos/1013203451), [Wolpert, Stacked Generalization](https://doi.org/10.1016/S0893-6080%2805%2980023-1).

## Build

1. Use the existing balanced endpoint sample of 24,576 historical labels and 768 cutoffs. Build the current self-history features at every endpoint. Add adaptive and matched no-lag win forecasts, their logit difference, short/long rate differences, and observed context support if available. Compute adaptive inputs at each row's actual time. A reference implementation can batch replay manifests with earlier cutoffs, one offset per pass, truncating all eight machine histories. Cache in your own lane and verify that cutoff replay matches the saved adaptive CSV.
2. Generate training base logits out of episode by fitting the adaptive population prior on other training episodes. For selecting the correction in four outer episode folds, build inner out-of-fold base features inside each outer training set, and fit a separate base on the entire outer training set for the outer held-out episodes. Alternatively, reserve a fixed disjoint group of training episodes to fit a shared base for the development run. Never let a held-out episode's payouts enter a population prior, scaler, or correction. Its own observed prefix is valid local evidence.
3. Fit `w = sigmoid(logit(clip(w_adaptive)) + g(x))` with binary log loss on natural outcomes. Begin with an intercept and one coefficient on the base logit, penalized toward zero correction. This is a calibration control. Then fit depth-2 trees with at least 100 rows per leaf, shrinkage 0.05, and 30 or 60 boosting rounds. With the available scikit-learn dependency, implement a small offset boosting loop using `DecisionTreeRegressor`. At each iteration use current `p`, curvature `h = max(p*(1-p), 1e-3)`, weighted Newton target `(y-p)/h`, and fit with sample weights `h` times any episode-balance weights. Clip leaf steps to a modest fixed range, such as `[-1,1]`, before applying shrinkage. Start the loop with the per-row adaptive logit. Keep the adaptive conditional payout mix fixed.
4. Compare zero correction, the calibration control, and shallow trees. Run a direct shallow classifier on the same features without the offset only if it will clarify a gain. Pick regularization and tree budget on grouped train folds using observed cutoff Brier, then fit a final correction on cross-fitted train features and use an all-train adaptive prior at inference. Allow one follow-up if the curves show a clear failure mode.

## Verification

- Setting `g=0` must reproduce every adaptive probability within `1e-12`. Validate the weighted Newton step against a one-leaf hand calculation. Verify that the first training iteration uses the supplied per-row logit and that inference applies the same offset before adding trees.
- For a historical row, modifying any own or peer payout at or after its time must leave its base forecast and features unchanged. Holding prefixes fixed, changing labels in a held-out episode must leave its global base priors and calibration fit unchanged.
- Report cutoff Brier/log loss in grouped train folds. On tuning, report official points, error by condition, `p_0` squared error, and binned predicted versus true win probabilities. Use confidence bins to diagnose whether a larger spread improves accuracy. Keep the adaptive fallback if the apparent gain rests on a few episodes.
